# Deployment Results

Generated deployment outputs are intentionally ignored by git.

Use this directory for local run outputs from the official SONIC / MuJoCo
preflight commands, such as heartbeat files, preflight JSON summaries, and
future verifier traces.

Do not treat local outputs as paper evidence until the run command, commit hash,
scene file, and verifier criteria are recorded.

## Static Skill Manifest

`static_skill_success_manifest.json` is the curated local index for the current
SONIC static skill library:

- dual synchronized walking;
- `elbow110_carry_ready` upper-body lock;
- carry-forward/backward;
- carry turn-in-place through incremental heading;
- carry place-crouch;
- carry lateral left/right.

The manifest records local manual validation state only. It is not SpecMemory
and is not generated by Qwen/Orchestrator evolution.
